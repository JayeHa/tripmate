# 시안과 달라진 점

디자인 핸드오프(시안)와 **일부러** 다르게 만든 것을 모은다. 시안을 앱에 맞춰 고칠 때 이 목록을 디자인 도구에 그대로 넘긴다(맨 아래 프롬프트).

- 담는 것: 동작 · 문구 · 색 · 배치를 시안과 다르게 정한 것, 사용자 결정으로 시안을 바꾼 것, 시안에 없는데 앱에 더한 것
- 담지 않는 것: 아직 만들지 않은 것 · 다음 단계로 미룬 것 · 버그 · 코드 정리
- **시안과 다르게 만들면 같은 PR 에서 여기에 한 줄 더한다.** 나중에 되돌리면 그 줄을 고친다
- 항목은 화면별로 「시안 · 앱 · 이유 · 출처(PR)」 를 적는다

## 새 여행

- **지난 날짜 선택**
  - 시안: 날짜 선택 달력에서 지난 날짜를 막는다(5c · 6c)
  - 앱: 지난 날짜도 고를 수 있다
  - 이유: 다녀온 여행도 기록하려고(사용자 요청)
  - 출처: #39
- **달력 범위**
  - 시안: 3개월만 그린다
  - 앱: 3년 전부터 1년 뒤까지 연다. 모바일은 세로 스크롤로 열 때 이번 달에 맞추고, PC 는 두 달씩 ◀▶ 로 넘긴다
  - 이유: 지난 여행 기록, 시안의 여행 수정 화면과 같은 범위
  - 출처: #39

## 일정 타임라인

- **「메모 N개」 세는 법**
  - 시안: 노트만 센다
  - 앱: 운영시간도 1개로 센다. 접힌 메모를 펼치면 노트와 운영시간이 함께 나온다
  - 이유: 노트 없이 운영시간만 있는 장소는 운영시간을 볼 방법이 없었다
  - 출처: #51
- **카드 설명 줄 수**
  - 시안: 일정 카드의 장소 설명(카테고리 · ★ · 한 줄 설명)을 길이 제한 없이 보인다
  - 앱: 2줄까지, 넘치면 「…」. 전체는 일정 상세에서
  - 이유: 긴 설명이 카드를 길게 늘려 하루 흐름이 한눈에 안 들어온다(사용자 요청)
  - 출처: 이 PR
- **여행지 공휴일 표시**
  - 시안: 일정 화면에는 공휴일 · 주말 색이 없다(날짜는 회색)
  - 앱: 공휴일이면 day 머리의 날짜 옆 · PC 레일의 날짜 아래에 빨간 이름(「Culture Day」, `--color-holiday` 13/600). 날짜(칩 · day 머리 · PC 레일)는 토 파랑(`brand`) · 일 · 공휴일 빨강(`destructive`)
  - 이유: 공휴일에는 가게가 쉬거나 붐비거나 입장이 제한돼 일정을 짤 때 알아야 한다. 주말 색은 가계부 날짜 줄과 맞춘다(사용자 요청)
  - 출처: #163

## 일정 상세

- **「장소 정보 수정」 의 「위치 변경」 에서 뒤로**
  - 시안: 닫는다
  - 앱: 장소 정보 단계로 돌아간다
  - 이유: 위치 변경은 장소 정보 안의 한 칸이라, 고친 칸을 잃지 않게
  - 출처: #85
- **「이번 일정 · 수정」 칸 수**
  - 시안: 3칸
  - 앱: 아이콘 칸을 더해 4칸. 비우면 장소의 예전 아이콘이 흐리게 보인다
  - 이유: 아이콘을 장소가 아니라 일정에 두기로 정했다(#83)
  - 출처: #85
- **항공편 상세의 ⋯ 메뉴**
  - 시안: 상세 머리에 ⋯(다른 날로 · 삭제)
  - 앱: 항공편 상세에는 ⋯ 가 없다. 일정 편집에서도 항공편은 고를 수 없다
  - 이유: 항공편은 항공편 화면(#89)에서 옮기고 지운다(사용자 결정)
  - 출처: #114, `docs/policies/schedule.md`

## 장소 입력

- **지역 칩**
  - 시안: 위치 고르기에 「도쿄역 · 긴자 · 신주쿠 …」 칩
  - 앱: 칩 없이 위치 검색으로 옮긴다
  - 이유: 지역 좌표 데이터가 없다(#76)
  - 출처: #77, #81
- **주소 표기**
  - 시안: 첫 줄이 한국어 주소(OpenStreetMap 결과)
  - 앱: 세 줄 — 로마자(구글 한국어 요청 결과) → 현지어 → 한글(한글 동네 이름 + 번지 숫자)
  - 이유: 공개 OSM 서버의 사용 제한과 새 외부 의존을 피했다(사용자 결정)
  - 출처: #81, `docs/policies/place-search.md`
- **핀 위치의 가게 이름을 받지 않음**
  - 시안: 핀 위치의 가게 이름(POI)을 쓰는 것으로 보인다
  - 앱: 장소 이름은 검색으로 고른 장소의 이름으로만 채운다
  - 이유: 구글 역지오코딩 결과의 한계
  - 출처: #81
- **시안에 없는 동작(사용자 요청)**
  - 앱: 검색 결과 맨 위 「이 주소로 이동」(주소 검색) · 검색 결과 목록을 지도 위에 띄움 · 구글 장소를 고르면 카테고리와 구글맵 링크를 자동으로 채움 · 이미 저장한 장소면 「이 장소를 쓸까요?」 확인 카드
  - 이유: 한국어로 적은 일본 주소는 찾을 수 없었다. 나머지는 입력 편의
  - 출처: #81
- **「휴식」 카테고리 색**
  - 시안: 휴식에 색이 없다
  - 앱: `cat-rest` #EC4899, 이모지 ♨️
  - 이유: 시안에 값이 없어 앱에서 정했다
  - 출처: #77

## 가계부 목록

- **모바일 「결제한 사람」 칩**
  - 시안: 모바일 목록에 사람 필터 없음(PC 필터 줄에만 「결제한 사람」)
  - 앱: 일행이 있으면 날짜 목록 위에 「결제한 사람 전체 · 정원 · 김동규」 칩 줄(P2 보조 30, 하나만). 고르면 그 사람이 낸 비용만 — 날짜 합계 · 날짜 줄도 따라가고, 맨 위 총 지출은 그대로. 각자 냄은 빠진다(PC 와 같다). 빈 날은 「결제한 지출이 없어요」. 고른 사람은 그 화면에서만 기억
  - 이유: 실제 도쿄 여행 중 모바일에서도 사람별로 보고 싶다는 피드백(2026-10-31 사용자 결정 — 기준은 결제한 사람)
  - 출처: #287

- **요약의 「내가 쓴 돈」 → 「내가 결제한 돈」**
  - 시안: 총 지출 오른쪽 「내가 쓴 돈」(내 몫의 합) — 모바일 목록 맨 위 카드 · 「지출 · 정산」 · PC 오른쪽 요약
  - 앱: 「내가 결제한 돈」 — 내가 결제한 비용의 합 + 「각자 냄」 의 내 몫(정산 카드의 「결제 N원」 과 같은 값, 결제 예정도 들어간다). 홈 「오늘 지출」 의 「내가 쓴 돈」 은 그대로
  - 이유: 요약에서 내가 얼마를 냈는지 보고 싶다는 요청(사용자 결정). 내 몫(쓴 돈)은 정산 카드 · 사람 상세에 남아 있다

  - 이유: 넷째부터의 금액 · 비율을 바로 보고 싶다는 요청(사용자 결정). 카테고리가 9개라 다 보여도 카드가 지나치게 길지 않다

  - 앱: 「₩466,240」 · 「≈ ₩29,440」(앱 공통 금액 표기)

## 비용 입력

- **장소(선택) — 일정에 없는 곳**
  - 시안: 「장소 (선택)」 칸은 시안 갱신에서 지웠다(일정 연결로 대신)
  - 앱: 일정을 연결하지 않았을 때만 항목명 아래 「장소 (선택)」 — 회색 검색 칸(P3) + 구글 결과 5곳, 고르면 이름 · 주소 상자 + ✕. 항목명이 비어 있으면 장소 이름, 카테고리를 안 골랐으면 장소 종류로 채운다. 오프라인이면 칸이 흐리고 「연결되면 찾을 수 있어요」. 비용 상세(모바일)는 「장소」 줄 + 「구글맵」, PC 상세 패널은 장소 이름이 구글맵 링크, PC 표는 항목명 아래(연결 일정 자리)에 장소 이름. 모바일 목록 줄에는 보이지 않는다
  - 이유: 편의점 · 약국처럼 일정엔 없는데 즉흥으로 들어가 결제한 곳을 남기고 싶다 — 실제 도쿄 여행 중 피드백(2026-10-31 · 11-01 사용자 결정)
  - 출처: #289

- **시간(선택)**
  - 시안: 비용에 시간 칸 없음 — 날짜만, 같은 날 안의 순서는 정하지 않음
  - 앱: 날짜 아래(일정을 연결했으면 「일정에서 가져옴」 아래, 빠른 입력은 항목명 아래) 「시간 (선택)」 TimeField. 손대지 않으면 연결한 일정의 시간, 아니면 쓴 날이 오늘이면 연 시각이 들어가 있고, ✕ 로 비운다. 여행준비면 칸이 없다. 목록은 같은 날 안에서 시각순(없는 비용은 맨 아래), 모바일 줄 「14:20 · 정원 결제 · 2명」, PC 표는 항목명 아래 「14:20 · 연결 일정」, 상세의 날짜 뒤에 시각
  - 이유: 몰아서 넣으면 같은 날 순서가 뒤섞였다 — 실제 도쿄 여행 중 피드백. 끌어서 순서 바꾸기는 일행과 동시에 고치거나 오프라인 대기열에서 부딪혀 시간 칸으로(2026-10-31 사용자 결정)
  - 출처: #288

- **결제수단 순서 · 기본값**
  - 시안: 현금 · 카드 · 교통카드, 새 비용은 현금
  - 앱: 카드 · 현금 · 교통카드, 새 비용은 늘 카드(마지막에 고른 수단은 기억하지 않는다). PC 필터의 결제수단도 같은 순서
  - 이유: 여행지에서 대부분 카드로 낸다 — 실제 도쿄 여행 중 피드백(2026-10-31 사용자 결정)
  - 출처: #286

- **「환율설정」 창의 통화 칸**
  - 시안: 통화 코드 옆 ⌄ 로 통화를 바꾼다
  - 앱: 코드만 보인다. 통화는 금액 칸의 통화 칩에서 바꾼다
  - 이유: 같은 일을 두 곳에서 하지 않게. 「다른 통화 추가」(⑪-b)에서 다시 정한다
  - 출처: #148

- **「다른 통화 추가」 목록**
  - 시안: 유로는 「그리스 - EUR(유로)」, 같은 이름 통화는 「달러」 · 「크로네」 · 「페소」 · 「루피」 그대로. 대한민국 · 일본 · 미국은 추가 목록에 없다
  - 앱: 유로는 「유럽연합」, 같은 이름은 나라를 붙인다(뉴질랜드 달러 · 노르웨이 크로네 …). 대한민국 · 일본 · 미국도 목록 맨 앞에 있고 이미 쓰면 「추가됨」. 목록 위에 「처음 환율은 대략 값이에요」 안내
  - 이유: 금액 옆 단위 · 「… 기준」 줄에서 통화를 가리려고. 처음 환율이 고정 값이라 확인을 권한다(사용자 결정)
  - 출처: ⑪-b PR
- **통화 칩**
  - 시안: 통화가 둘 이상일 때 칩으로 고른다
  - 앱: 통화가 하나여도 칩이 보인다(「다른 통화 추가」 로 가는 길)
  - 이유: 통화가 기준 화폐 하나뿐인 여행도 외화를 더할 수 있게
  - 출처: ⑪-b PR
- **처음 통화**
  - 시안: 정하지 않음
  - 앱: 이 여행에서 마지막에 고른 통화(기기별) → 가장 많이 쓴 통화 → 첫 외화 → 기준 통화
  - 이유: 통화를 더하면 기본이 바뀌던 것(사용자 요청)
  - 출처: #167
- **「일정에서 가져옴」 묶음의 날짜 불일치 안내**
  - 시안: 날짜가 연결 일정과 다르다는 안내(「연결된 일정은 day N이에요」)는 「수정」 으로 연 입력칸에서만
  - 앱: 글로 볼 때도 묶음 아래에 같은 안내

  - 출처: `docs/policies/schedule.md`(#113)
- **입력칸을 눌러도 화면을 키우지 않음**
  - 시안: 입력칸 글자 13~15px(정하지 않은 것: iOS 는 16px 보다 작은 입력칸을 누르면 화면을 확대한다)
  - 앱: 화면 설정(viewport)의 최대 배율을 1로 — 글자 크기는 시안대로 두고 자동 확대만 끈다. 안드로이드는 손가락 확대도 막힌다
  - 이유: 누를 때마다 확대되고 키보드를 닫아도 그대로라 화면이 잘렸다(2026-10-30 사용자 결정). 입력칸을 16px 로 키우는 대신 시안 크기를 지켰다
  - 출처: #254

- **홈 화면에 추가 안내 — 앱 아이콘**
  - 시안: 파란 칸에 흰 「t」(임시, 512 · 192 PNG 가 정해지면 바꾼다고 함)
  - 앱: 지금 manifest 의 앱 아이콘(`/icons/icon-192.png`, 파란 바탕 핀)
  - 이유: 홈 화면에 실제로 생기는 아이콘을 보여 주려고 — 앱 아이콘은 이미 있다
  - 출처: 설치 안내 시트(P40)
- **홈 화면에 추가 안내 — 계정 메뉴에서 「주소 복사」**
  - 시안: 앱 안 브라우저에서 「주소 복사」 를 누르면 토스트 「주소를 복사했어요」
  - 앱: 자동으로 뜨는 시트는 토스트, 계정 메뉴의 「홈 화면에 앱 추가」 안에서는 버튼 아래 「주소를 복사했어요」 한 줄
  - 이유: 계정 메뉴는 여러 화면이 함께 쓰는 창이라 토스트를 쥔 화면이 없다(토스트는 화면이 그린다)
  - 출처: 설치 안내 시트(P40)

## 확인 필요

PR 본문만으로는 시안과 다른지, 이전 구현과만 다른지 가리지 못한 것. 시안과 맞춰 볼 때 함께 확인한다.

- **직접 나누기 제거**(#130): 사람마다 금액을 정하는 칸을 빼고 늘 균등 분할(2026-10-06 결정). 시안에 직접 나누기가 남아 있는지
- **대체 장소 연결**(#133): 일정 고르기 시트에 대체 장소 줄도 「대체 장소 · …」 로 보이고 연결할 수 있다(#91)
- **「다른 날로」 메뉴**(#114): 옆으로 펼치는 하위 메뉴 대신 같은 메뉴가 day 목록으로 바뀐다
- **일정 편집**: 여러 개를 묶어 끌지 않고 「날짜 이동」 을 쓴다(사용자 결정, `docs/policies/schedule.md`)
- **보기 설정**(#104): 모바일은 「이어서」 만, PC 만 「이어서 / 하루씩」
- **새 여행 제목**(#39): 「도쿄·오사카 여행」 처럼 도시로 자동으로 짓는다
