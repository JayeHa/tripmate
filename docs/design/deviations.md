# 시안과 달라진 점

디자인 핸드오프(시안)와 **일부러** 다르게 만든 것을 모은다. 시안을 앱에 맞춰 고칠 때 이 목록을 디자인 도구에 그대로 넘긴다(맨 아래 프롬프트).

- 담는 것: 동작 · 문구 · 색 · 배치를 시안과 다르게 정한 것, 사용자 결정으로 시안을 바꾼 것, 시안에 없는데 앱에 더한 것
- 담지 않는 것: 아직 만들지 않은 것 · 다음 단계로 미룬 것 · 버그 · 코드 정리
- **시안과 다르게 만들면 같은 PR 에서 여기에 한 줄 더한다.** 나중에 되돌리면 그 줄을 고친다
- 항목은 화면별로 「시안 · 앱 · 이유 · 출처(PR)」 를 적는다

## 새 여행

- **지난 날짜 선택**
  - 시안: 날짜 선택 달력에서 지난 날짜를 막는다(5c · 6c)
  - 앱: 지난 날짜도 고를 수 있다
  - 이유: 다녀온 여행도 기록하려고(사용자 요청)
  - 출처: #39
- **달력 범위**
  - 시안: 3개월만 그린다
  - 앱: 3년 전부터 1년 뒤까지 연다. 모바일은 세로 스크롤로 열 때 이번 달에 맞추고, PC 는 두 달씩 ◀▶ 로 넘긴다
  - 이유: 지난 여행 기록, 시안의 여행 수정 화면과 같은 범위
  - 출처: #39

## 일정 타임라인

- **「메모 N개」 세는 법**
  - 시안: 노트만 센다
  - 앱: 운영시간도 1개로 센다. 접힌 메모를 펼치면 노트와 운영시간이 함께 나온다
  - 이유: 노트 없이 운영시간만 있는 장소는 운영시간을 볼 방법이 없었다
  - 출처: #51

## 일정 상세

- **「장소 정보 수정」 의 「위치 변경」 에서 뒤로**
  - 시안: 닫는다
  - 앱: 장소 정보 단계로 돌아간다
  - 이유: 위치 변경은 장소 정보 안의 한 칸이라, 고친 칸을 잃지 않게
  - 출처: #85
- **「이번 일정 · 수정」 칸 수**
  - 시안: 3칸
  - 앱: 아이콘 칸을 더해 4칸. 비우면 장소의 예전 아이콘이 흐리게 보인다
  - 이유: 아이콘을 장소가 아니라 일정에 두기로 정했다(#83)
  - 출처: #85
- **항공편 상세의 ⋯ 메뉴**
  - 시안: 상세 머리에 ⋯(다른 날로 · 삭제)
  - 앱: 항공편 상세에는 ⋯ 가 없다. 일정 편집에서도 항공편은 고를 수 없다
  - 이유: 항공편은 항공편 화면(#89)에서 옮기고 지운다(사용자 결정)
  - 출처: #114, `docs/policies/schedule.md`

## 장소 입력

- **지역 칩**
  - 시안: 위치 고르기에 「도쿄역 · 긴자 · 신주쿠 …」 칩
  - 앱: 칩 없이 위치 검색으로 옮긴다
  - 이유: 지역 좌표 데이터가 없다(#76)
  - 출처: #77, #81
- **주소 표기**
  - 시안: 첫 줄이 한국어 주소(OpenStreetMap 결과)
  - 앱: 세 줄 — 로마자(구글 한국어 요청 결과) → 현지어 → 한글(한글 동네 이름 + 번지 숫자)
  - 이유: 공개 OSM 서버의 사용 제한과 새 외부 의존을 피했다(사용자 결정)
  - 출처: #81, `docs/policies/place-search.md`
- **핀 위치의 가게 이름을 받지 않음**
  - 시안: 핀 위치의 가게 이름(POI)을 쓰는 것으로 보인다
  - 앱: 장소 이름은 검색으로 고른 장소의 이름으로만 채운다
  - 이유: 구글 역지오코딩 결과의 한계
  - 출처: #81
- **시안에 없는 동작(사용자 요청)**
  - 앱: 검색 결과 맨 위 「이 주소로 이동」(주소 검색) · 검색 결과 목록을 지도 위에 띄움 · 구글 장소를 고르면 카테고리와 구글맵 링크를 자동으로 채움 · 이미 저장한 장소면 「이 장소를 쓸까요?」 확인 카드
  - 이유: 한국어로 적은 일본 주소는 찾을 수 없었다. 나머지는 입력 편의
  - 출처: #81
- **「휴식」 카테고리 색**
  - 시안: 휴식에 색이 없다
  - 앱: `cat-rest` #EC4899, 이모지 ♨️
  - 이유: 시안에 값이 없어 앱에서 정했다
  - 출처: #77

## 가계부 목록

- **금액 표기**
  - 시안: 「₩ 466,240」 · 「≈ 29,440원」
  - 앱: 「₩466,240」 · 「≈ ₩29,440」(앱 공통 금액 표기)
  - 이유: 다른 화면과 통일
  - 출처: #124 · #135 · #136
- **PC 표 금액 보기 이름**
  - 시안: 「현지 금액 | 원화」
  - 앱: 「결제 통화 | 원화 환산」. 기준 화폐가 원화가 아니면 「JPY 환산」 · 「USD 환산」 처럼 통화 코드
  - 이유: 기준 화폐가 엔이면 「원화」 가 틀린 이름이 된다(사용자 요청)
  - 출처: #148

## 비용 입력

- **「환율설정」 창의 통화 칸**
  - 시안: 통화 코드 옆 ⌄ 로 통화를 바꾼다
  - 앱: 코드만 보인다. 통화는 금액 칸의 통화 칩에서 바꾼다
  - 이유: 같은 일을 두 곳에서 하지 않게. 「다른 통화 추가」(⑪-b)에서 다시 정한다
  - 출처: #148

## 비용 상세

- **PC 비용 상세 위치**
  - 시안: README 「비용 상세」 항목은 PC 를 480×760 가운데 창으로, PC 가계부 확정 시안(48c)은 오른쪽 패널로 적어 서로 다르다
  - 앱: 48c 를 따라 오른쪽 패널. 「수정」 은 440×760 비용 입력 창을 열고, 삭제도 그 창에서 한다
  - 이유: 확정 시안을 따랐다. README 쪽을 고쳐야 한다
  - 출처: #140, #141
- **저장 뒤 이동(모바일)**
  - 시안: 프로토타입은 저장 뒤 목록으로 간다
  - 앱: 수정을 저장하거나 닫으면 상세로 돌아온다. 지웠을 때만 가계부로 간다
  - 이유: 고친 결과를 바로 보게
  - 출처: #140

## 지출 · 정산

- **카테고리 상세의 날짜별 막대**
  - 시안: 날짜별 막대를 늘 보인다
  - 앱: 그 카테고리 지출이 서로 다른 날 2일 이상일 때만. 그때는 day 1~N 을 지출이 없어도 칸으로 두고(긴 여행은 막대 줄만 좌우 스크롤), 「여행준비」 칸은 지출이 있을 때만 맨 앞에
  - 이유: 사용자 결정
  - 출처: #145
- **정산 사람 상세의 「보낼 돈」 색**
  - 시안: 상자 #FFF1E6, 버튼 테두리 #FAD3AE
  - 앱: 기존 토큰 `status-wait-bg`(#FEEEE7) · `status-wait-line`
  - 이유: 「예정일 지남」 과 같은 주황 계열이라 토큰을 새로 만들지 않았다
  - 출처: #146
- **「어떻게 계산하나요?」**
  - 시안: 마우스를 올리면 뜨는 설명
  - 앱: 눌러서 펼친다
  - 이유: 터치 화면에는 마우스 올리기가 없다
  - 출처: #146
- **송금 기록 취소**
  - 시안: 「받았어요 ✓」 · 체크를 다시 누르면 바로 되돌린다
  - 앱: 「송금 기록을 취소할까요?」 확인 창(그대로 두기 | 기록 취소)을 거친다
  - 이유: 실수로 누른 한 번에 보낸 기록이 지워지지 않게(사용자 요청)
  - 출처: #148
- **PC 요약 카드의 「지출내역 보기」**
  - 시안: 요약 카드를 펼치면 「지출내역 보기 ›」
  - 앱: PC 에는 두지 않는다(모바일만)
  - 이유: PC 는 같은 내용(카테고리 · 정산 카드)이 바로 아래에 있다
  - 출처: #146

## 여행 설정

- **기준 화폐 바꾸기**
  - 시안: 여행 정보 편집에서 기준 화폐 · 환율을 바로 고친다
  - 앱: 기준 화폐를 바꿔 저장하면 확인 창 「기준 화폐를 원 → 엔으로 바꿀까요?」 — 새 기준으로 다시 계산한 여행 환율을 보여 주고, 지출별 환율 · 송금 기록도 함께 다시 계산한다. 옛 환율에 새 기준 화폐가 없으면 「1 USD = [ ] KRW」 를 물어 넣어야 바꿀 수 있다
  - 이유: 기준 화폐만 바꾸면 옛 기준으로 쓴 지출이 「환율이 없어 합계에서 빠졌어요」 가 된다(사용자 결정)
  - 출처: ⑪-c PR

## 공통

- **확인 창 모양 통일**
  - 시안: 「편집한 내용을 버릴까요?」 창에만 정해진 규칙, 다른 확인 창은 제각각
  - 앱: 그 규칙을 모든 확인 창에 — 왼쪽 정렬 제목 18/800(PC 19) · 본문 14 #666 · 구분선 없음 · 버튼 가로 한 줄(취소 회색 | 지우기 · 버리기 빨강 채움) · 바깥을 누르면 취소
  - 이유: 확인 창을 하나로 맞추려고
  - 출처: #105
- **시간 입력**
  - 시안: 목록에서 시간을 고르는 칸
  - 앱: 칸 안에서 「시 · 분」 을 직접 친다. 확인 버튼 없이 칸 밖으로 나가거나 Enter 로 확정
  - 이유: 목록이 화면 밖으로 잘렸고 키보드 입력으로 충분했다(2026-10-05 사용자 결정)
  - 출처: `docs/policies/schedule.md`(#113)

## 확인 필요

PR 본문만으로는 시안과 다른지, 이전 구현과만 다른지 가리지 못한 것. 시안과 맞춰 볼 때 함께 확인한다.

- **직접 나누기 제거**(#130): 사람마다 금액을 정하는 칸을 빼고 늘 균등 분할(2026-10-06 결정). 시안에 직접 나누기가 남아 있는지
- **대체 장소 연결**(#133): 일정 고르기 시트에 대체 장소 줄도 「대체 장소 · …」 로 보이고 연결할 수 있다(#91)
- **「다른 날로」 메뉴**(#114): 옆으로 펼치는 하위 메뉴 대신 같은 메뉴가 day 목록으로 바뀐다
- **일정 편집**: 여러 개를 묶어 끌지 않고 「날짜 이동」 을 쓴다(사용자 결정, `docs/policies/schedule.md`)
- **보기 설정**(#104): 모바일은 「이어서」 만, PC 만 「이어서 / 하루씩」
- **새 여행 제목**(#39): 「도쿄·오사카 여행」 처럼 도시로 자동으로 짓는다

```
- 각 항목은 「시안 → 앱」 으로 적혀 있어요. 「앱」 쪽이 최종이에요.

- 고친 화면 id(예: 48c, 9d)와 바뀐 점을 한 줄씩 정리해서 돌려주세요.

(여기에 위의 화면별 목록을 붙여 넣는다)
```
