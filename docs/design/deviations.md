# 시안과 달라진 점

디자인 핸드오프(시안)와 **일부러** 다르게 만든 것을 모은다. 시안을 앱에 맞춰 고칠 때 이 목록을 디자인 도구에 그대로 넘긴다(맨 아래 프롬프트).

- 담는 것: 동작 · 문구 · 색 · 배치를 시안과 다르게 정한 것, 사용자 결정으로 시안을 바꾼 것, 시안에 없는데 앱에 더한 것
- 담지 않는 것: 아직 만들지 않은 것 · 다음 단계로 미룬 것 · 버그 · 코드 정리
- **시안과 다르게 만들면 같은 PR 에서 여기에 한 줄 더한다.** 나중에 되돌리면 그 줄을 고친다
- 항목은 화면별로 「시안 · 앱 · 이유 · 출처(PR)」 를 적는다

## 새 여행

- **지난 날짜 선택**
  - 시안: 날짜 선택 달력에서 지난 날짜를 막는다(5c · 6c)
  - 앱: 지난 날짜도 고를 수 있다
  - 이유: 다녀온 여행도 기록하려고(사용자 요청)
  - 출처: #39
- **달력 범위**
  - 시안: 3개월만 그린다
  - 앱: 3년 전부터 1년 뒤까지 연다. 모바일은 세로 스크롤로 열 때 이번 달에 맞추고, PC 는 두 달씩 ◀▶ 로 넘긴다
  - 이유: 지난 여행 기록, 시안의 여행 수정 화면과 같은 범위
  - 출처: #39

## 일정 타임라인

- **「메모 N개」 세는 법**
  - 시안: 노트만 센다
  - 앱: 운영시간도 1개로 센다. 접힌 메모를 펼치면 노트와 운영시간이 함께 나온다
  - 이유: 노트 없이 운영시간만 있는 장소는 운영시간을 볼 방법이 없었다
  - 출처: #51

## 일정 상세

- **「장소 정보 수정」 의 「위치 변경」 에서 뒤로**
  - 시안: 닫는다
  - 앱: 장소 정보 단계로 돌아간다
  - 이유: 위치 변경은 장소 정보 안의 한 칸이라, 고친 칸을 잃지 않게
  - 출처: #85
- **「이번 일정 · 수정」 칸 수**
  - 시안: 3칸
  - 앱: 아이콘 칸을 더해 4칸. 비우면 장소의 예전 아이콘이 흐리게 보인다
  - 이유: 아이콘을 장소가 아니라 일정에 두기로 정했다(#83)
  - 출처: #85
- **항공편 상세의 ⋯ 메뉴**
  - 시안: 상세 머리에 ⋯(다른 날로 · 삭제)
  - 앱: 항공편 상세에는 ⋯ 가 없다. 일정 편집에서도 항공편은 고를 수 없다
  - 이유: 항공편은 항공편 화면(#89)에서 옮기고 지운다(사용자 결정)
  - 출처: #114, `docs/policies/schedule.md`

## 장소 입력

- **지역 칩**
  - 시안: 위치 고르기에 「도쿄역 · 긴자 · 신주쿠 …」 칩
  - 앱: 칩 없이 위치 검색으로 옮긴다
  - 이유: 지역 좌표 데이터가 없다(#76)
  - 출처: #77, #81
- **주소 표기**
  - 시안: 첫 줄이 한국어 주소(OpenStreetMap 결과)
  - 앱: 세 줄 — 로마자(구글 한국어 요청 결과) → 현지어 → 한글(한글 동네 이름 + 번지 숫자)
  - 이유: 공개 OSM 서버의 사용 제한과 새 외부 의존을 피했다(사용자 결정)
  - 출처: #81, `docs/policies/place-search.md`
- **핀 위치의 가게 이름을 받지 않음**
  - 시안: 핀 위치의 가게 이름(POI)을 쓰는 것으로 보인다
  - 앱: 장소 이름은 검색으로 고른 장소의 이름으로만 채운다
  - 이유: 구글 역지오코딩 결과의 한계
  - 출처: #81
- **시안에 없는 동작(사용자 요청)**
  - 앱: 검색 결과 맨 위 「이 주소로 이동」(주소 검색) · 검색 결과 목록을 지도 위에 띄움 · 구글 장소를 고르면 카테고리와 구글맵 링크를 자동으로 채움 · 이미 저장한 장소면 「이 장소를 쓸까요?」 확인 카드
  - 이유: 한국어로 적은 일본 주소는 찾을 수 없었다. 나머지는 입력 편의
  - 출처: #81
- **「휴식」 카테고리 색**
  - 시안: 휴식에 색이 없다
  - 앱: `cat-rest` #EC4899, 이모지 ♨️
  - 이유: 시안에 값이 없어 앱에서 정했다
  - 출처: #77

  - 시안: 「현지 금액 | 원화」

  - 이유: 기준 화폐가 엔이면 「원화」 가 틀린 이름이 된다(사용자 요청)
  - 출처: #148
- **금액순일 때 날짜 레일 누르기**
  - 시안: 레일 선택만 바뀌고 표는 그대로(날짜 묶음이 없어 갈 곳이 없다)
  - 앱: 최신순으로 돌아가 그 날 묶음으로 스크롤
  - 이유: 눌러도 아무 일이 없으면 고장처럼 보인다
  - 출처: ⑤-b PR
- **PC 필터 여러 개 고르기 목록**
  - 시안: 드롭다운의 여러 개 고르기 모양이 따로 없다(시트는 원형 체크 26 + 「적용」)
  - 앱: 하나 고르기와 같은 줄(고르면 블루 + ✓), 누를 때마다 바로 걸리고 목록은 열려 있다. 「적용」 버튼 없음 — 바깥 · Esc 로 닫기
  - 이유: 걸린 결과가 표에 바로 보여 「적용」 이 할 일이 없다
  - 출처: ⑤-b PR

## 비용 입력

- **「환율설정」 창의 통화 칸**
  - 시안: 통화 코드 옆 ⌄ 로 통화를 바꾼다
  - 앱: 코드만 보인다. 통화는 금액 칸의 통화 칩에서 바꾼다
  - 이유: 같은 일을 두 곳에서 하지 않게. 「다른 통화 추가」(⑪-b)에서 다시 정한다
  - 출처: #148

- **「다른 통화 추가」 목록**
  - 시안: 유로는 「그리스 - EUR(유로)」, 같은 이름 통화는 「달러」 · 「크로네」 · 「페소」 · 「루피」 그대로. 대한민국 · 일본 · 미국은 추가 목록에 없다
  - 앱: 유로는 「유럽연합」, 같은 이름은 나라를 붙인다(뉴질랜드 달러 · 노르웨이 크로네 …). 대한민국 · 일본 · 미국도 목록 맨 앞에 있고 이미 쓰면 「추가됨」. 목록 위에 「처음 환율은 대략 값이에요」 안내
  - 이유: 금액 옆 단위 · 「… 기준」 줄에서 통화를 가리려고. 처음 환율이 고정 값이라 확인을 권한다(사용자 결정)
  - 출처: ⑪-b PR
- **통화 칩**
  - 시안: 통화가 둘 이상일 때 칩으로 고른다
  - 앱: 통화가 하나여도 칩이 보인다(「다른 통화 추가」 로 가는 길)
  - 이유: 통화가 기준 화폐 하나뿐인 여행도 외화를 더할 수 있게
  - 출처: ⑪-b PR
- **처음 통화**
  - 시안: 정하지 않음
  - 앱: 이 여행에서 마지막에 고른 통화(기기별) → 가장 많이 쓴 통화 → 첫 외화 → 기준 통화
  - 이유: 통화를 더하면 기본이 바뀌던 것(사용자 요청)
  - 출처: #167
- **「일정에서 가져옴」 묶음의 날짜 불일치 안내**
  - 시안: 날짜가 연결 일정과 다르다는 안내(「연결된 일정은 day N이에요」)는 「수정」 으로 연 입력칸에서만
  - 앱: 글로 볼 때도 묶음 아래에 같은 안내
  - 이유: 묶음은 날짜를 「2026.10.31 (토) · day 1」 처럼 보여 주기만 해서, 연결 일정과 다른 날로 저장되는 걸 놓치기 쉽다
  - 출처: ②-b PR
- **휴식 일정의 비용 카테고리**
  - 시안: 정하지 않음(비용 카테고리에 휴식이 없다)
  - 앱: 휴식 일정에 연결하면 카테고리를 「관광」 으로 채운다. 일정 연결 창의 카테고리 필터에는 휴식이 없다(「전체」 에서만 보인다)
  - 이유: 휴식에서 나가는 돈은 온천 · 스파 · 정원 입장료처럼 입장 · 체험 성격이다. 카테고리를 새로 만들면 대시보드 · 누적 막대 순서 · 색까지 바뀌어 디자인과 함께 정한다(사용자 결정)
  - 출처: #168
- **접힌 「누가 내고, 누구와 나눴나요?」 카드의 제목**
  - 시안: 접히면 제목을 「누가 내고, 누구와」 로 줄인다
  - 앱: 접혀도 「누가 내고, 누구와 나눴나요?」 그대로
  - 이유: 펼친 카드와 같은 제목이라 같은 칸임을 알아보기 쉽게(사용자 요청)
  - 출처: #169
- **「일정에서 가져옴」 묶음 — 카테고리가 비었을 때**
  - 시안: 연결 일정 종류로 카테고리를 못 정해도(카테고리 없는 장소) 글로 보인다
  - 앱: 처음부터 입력칸(블루 테두리)으로 열고, 고르기 전엔 「닫기」 를 숨긴다
  - 이유: 카테고리는 필수라 글로 숨겨 두면 「완료」 가 꺼진 이유를 알 수 없다
  - 출처: ②-b PR

## 비용 상세

- **PC 비용 상세 위치**
  - 시안: README 「비용 상세」 항목은 PC 를 480×760 가운데 창으로, PC 가계부 확정 시안(48c)은 오른쪽 패널로 적어 서로 다르다
  - 앱: 48c 를 따라 오른쪽 패널. 「수정」 은 440×760 비용 입력 창을 열고, 삭제도 그 창에서 한다
  - 이유: 확정 시안을 따랐다. README 쪽을 고쳐야 한다
  - 출처: #140, #141
- **저장 뒤 이동(모바일)**
  - 시안: 프로토타입은 저장 뒤 목록으로 간다
  - 앱: 수정을 저장하거나 닫으면 상세로 돌아온다. 지웠을 때만 가계부로 간다
  - 이유: 고친 결과를 바로 보게
  - 출처: #140

- **영수증 보기**
  - 시안: 모바일 비용 상세에 영수증 96 칸 묶음. PC 오른쪽 상세 패널에는 영수증이 없다. 크게 보는 화면은 영수증 뷰어(아직 시안만)
  - 앱: PC 패널에도 56 칸 묶음을 둔다. 칸을 누르면 새 창에서 원본(서명 주소)을 연다 — 뷰어를 만들면 바꾼다
  - 이유: PC 에서도 영수증을 확인할 길이 필요했다
  - 출처: ⑫-a PR

## 지출 · 정산

  - 앱: 「기준 화폐로 바꿔 계산해요」, 받을/보낼 돈 끝에 「「보냈어요 · 받았어요」 로 표시한 돈은 빼요.」 를 더한다

- **기준 화폐 바꾸기**
  - 시안: 여행 정보 편집에서 기준 화폐 · 환율을 바로 고친다
  - 앱: 기준 화폐를 바꿔 저장하면 확인 창 「기준 화폐를 원 → 엔으로 바꿀까요?」 — 새 기준으로 다시 계산한 여행 환율을 보여 주고, 지출별 환율 · 송금 기록도 함께 다시 계산한다. 옛 환율에 새 기준 화폐가 없으면 「1 USD = [ ] KRW」 를 물어 넣어야 바꿀 수 있다
  - 이유: 기준 화폐만 바꾸면 옛 기준으로 쓴 지출이 「환율이 없어 합계에서 빠졌어요」 가 된다(사용자 결정)
  - 출처: ⑪-c PR
